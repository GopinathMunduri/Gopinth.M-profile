# Gopinath Munduri – Resume Website

This folder is ready for GitHub Pages.

## Files
- `index.html` – main website
- `profile.jpg` – profile photo

## Publish on GitHub Pages
1. Create a new GitHub repository, for example: `gopinath-resume`
2. Upload `index.html` and `profile.jpg` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** branch and **/ (root)** folder, then click **Save**.
6. GitHub will provide your website address, usually:
   `https://YOUR-USERNAME.github.io/gopinath-resume/`

The site is responsive and works on mobile and desktop.
